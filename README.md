# アドバンテージ仲間オーディション

株式会社アドプレイスの採用案内ページです。GitHub Pagesで配信できる静的HTMLで、ビルドやサーバーの設定は不要です。

## ファイル

```text
index.html
.nojekyll
assets/
  BG_Ichigo_red.jpg
  ichigo_sekkyaku.jpg
```

画像2枚がそろってから公開してください。

## GitHub Pagesで公開

1. 公開用のGitHubリポジトリを作成します。名前の例は `advantage-audition` です。
2. このフォルダの中身を、リポジトリのルートにアップロードします。`index.html` が直下に来るようにしてください。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment → Source** を **Deploy from a branch** にします。
5. **Branch** は **main**、フォルダは **/(root)** を選んで保存します。
6. ビルド完了後、Pages画面に表示される公開URLで確認します。
